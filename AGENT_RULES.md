# AI CODING RULES

1. Read docs/PROJECT_REQUIREMENTS.md before implementing requirements.

2. Read docs/ARCHITECTURE.md before modifying architecture.

3. Read docs/UI_UX_SPECIFICATION.md before implementing UI.

4. Read docs/AGENTS.md before implementing AI agents.

5. Do not invent requirements.

6. Do not change the technology stack without asking.

7. Do not create duplicate services.

8. Do not directly modify the database from an AI agent.

9. All database access must go through backend services/repositories.

10. All AI recommendations must have deterministic validation.

11. Every AI/ML component must have a fallback.

12. Do not hardcode API keys.

13. Use environment variables.

14. Do not implement everything in one file.

15. Keep modules separated.

16. Write tests for important algorithms.

17. Update documentation when architecture changes.

18. Never mark a feature complete unless it actually works.

19. Before changing existing functionality, inspect the existing implementation.

20. Prefer simple, maintainable implementations over unnecessary complexity.
